# UTAVISTA

![UTAVISTA Screenshot](./docs/images/utavista_16-9.jpg)

UTAVISTA（うたびすた）v0.8.0は、歌詞アニメーション動画を作成するためのElectronベースのデスクトップアプリケーションです。カラオケスタイルのテキストアニメーションをテンプレートベースで簡単に作成し、高品質な動画として出力できます。

## アプリケーション名について

「UTAVISTA」は「歌（UTA）」と「眺望（VISTA）」を組み合わせた造語です。歌の持つイメージや感情を視覚的に表現し、聴き手に新しい音楽体験を提供することを目指しています。

## 機能

- 階層的なタイムライン編集（フレーズ、単語、文字単位）
- **歌詞編集機能**（テキスト・タイミング・フレーズ管理、単語マージ機能）
- テンプレートベースのアニメーションシステム
- **キネティック・シーンコンポーザー**（出現・継続・消失・画面モーションと11系統のタイポグラフィエフェクトを自由に合成、内蔵プリセット26種）
- リアルタイムプレビュー（PIXI.js WebGL レンダリング）
- 高品質な動画エクスポート（WebCodecs使用、縦長1080×1920などハードウェア非対応の設定はソフトウェアエンコードで出力）
- **背景動画機能**（自動ループレンダリング対応）
- **透過背景での書き出し**（ProRes 4444 / .mov、アルファチャンネル付き）
- **柔軟な出力範囲設定**（全区間・指定時間範囲の選択出力）
- カスタマイズ可能なテンプレートパラメータ
- 音声ファイル対応とタイミング同期
- プロジェクトファイル保存・読み込み機能

## 更新履歴

### v0.8.0 (現在のバージョン - プレベータ版)

#### 新機能
- **キネティック・シーンコンポーザー**: レイアウト／出現／継続／消失／画面モーションを組み合わせる決定論的テンプレート
  - `sequence`、`parallel`、`delay`、`repeat` と共通イージングをTypeScriptから利用可能
  - 同一時刻・同一seedに対して常に同じ描画結果を生成
- **シーン設定タブ**: テンプレートタブを置き換え、シーン設定プリセットを基本設定または選択した単語・フレーズへ適用
  - 設定は「単語の個別設定 → フレーズの個別設定 → 基本シーン設定」の順に解決（文字を選ぶと、その文字を含む単語が編集対象）
  - 現在の設定を名前付きプリセットとして保存・上書き・削除でき、別のプロジェクトでも再利用可能
- **サイドパネルのタブ構成を整理**: シーン／コンテンツ／プロジェクト／書き出し／設定の5タブ
  - 書き出しタブに動画・静止画（PNG）・字幕（SRT）の出力をまとめ、プロジェクトタブは保存・読み込み専用に
  - デバッグ情報は設定タブ内の「開発者向け」に折りたたんで表示
- **タイポグラフィエフェクト**: 文字シャッフル、反復複製、有機ディストーション、弾性破壊、文字オブジェクト放出、文字曲面、可変ウェイトパルス、キネティックカーニング、ベースラインウェーブを個別にON/OFFして合成
  - 公開事例の手法を独自実装した内蔵プリセット 01A〜09B（詳細は `/docs/motion-reference-implementations.md`）
- **キネティック・シーンに参考モーションを追加**（[動きの引き出し](https://kumagi.com/motions/) の解説をもとに独自実装）
  - 出現・消失: `soft`（ぼかしから澄む）、`anticipate`（予備動作）、`spring`（減衰ばね）、`bounce`（スカッシュ＆ストレッチ）、`turnstile`（回転ドア）、`mask`（マスク開口）、`genie`（吸い込み）
  - 継続: `breathe`（吸う・止める・吐くの呼吸リズム）
  - 画面全体: `whipPan`（横流しの場面転換）、`zoomDive`（潜り込むズーム）
  - エフェクト: カラオケ塗り（発声中の文字を左→右に塗る）、二重輪郭インパクト、放出スタイル `speedLines`（集中線）
  - 内蔵プリセット 10A〜14B（Drop Word、Soft Enter、Karaoke Fill、Spring / Genie、Squash & Stretch、Turnstile、Impact、Whip Pan）
- **全シーン共通 Post FX**: 背景・文字・装飾を合成した後の画面全体に一度だけ適用
  - カメラシェイク、ズーム、傾き、グリッチ、水平うねり、色相回転、色収差、ビネット、フィルムグレイン、走査線、彩度、コントラスト
  - 設定はプロジェクトファイルに保存され、動画・静止画の書き出しにも反映
- **ビート検出システムを統合**: 音楽のリズムに同期したアニメーション制御
  - BeatManager: 再生・シークに追従するビートイベント管理
  - コンテンツタブでの検出設定とタイムライン上のビートマーカー表示
- **字幕（SRT）出力**: 歌詞のフレーズ開始・終了時刻から SubRip 字幕ファイルを書き出し
- **静止画（PNG）出力**: 現在のフレームを Post FX 込みで PNG に書き出し
- **フォントの書体（ウェイト）選択**: フォントごとに選べる太さを表示し、可変フォントにも対応
- **プロジェクト操作の強化**
  - 別名で保存、Ctrl/Cmd+S はどの編集欄にフォーカスがあっても保存、Ctrl/Cmd+O で開く
  - `.uta` ファイルをアプリに関連付け、ダブルクリックや「プログラムから開く」で読み込み
- **編集履歴**: Undo（Ctrl/Cmd+Z）・Redo（Ctrl/Cmd+Shift+Z、Ctrl+Y）。タイムライン上の編集も取り消し可能
- **タイムラインの連続ズーム**: 表示範囲を2秒から曲全体まで段階なしに変更。Ctrl/Cmd+ホイール（トラックパッドのピンチ）でマウス位置を基準に拡大縮小、スライダーで直接指定、ボタンは滑らかに1.5倍ずつ変化
- **終了時の未保存確認**: 未保存の変更があるままアプリを閉じると「保存して終了／保存せずに終了／キャンセル」を確認。プロジェクトタブにも未保存の変更を表示
- **Space キーで再生・一時停止**（入力欄の操作中を除く）
- **FFmpeg / FFprobe を同梱**: 別途インストールせずに動画を書き出せるようになりました（詳細は「FFmpeg について」を参照）
- **透過背景と透過動画の書き出し**: 背景タイプに「透過」を追加し、文字と装飾だけをアルファチャンネル付きの ProRes 4444（.mov）で書き出し
  - プレビューでは透明部分を市松模様で表示（書き出しには含まれません）
  - 音声は編集用の中間素材として非圧縮PCM（24bit・48kHz）で格納
  - 共通 Post FX も透明部分に色を足さずに適用

## インストール方法

### 必要な環境

- Node.js 18以上
- npm
- Electron対応OS（Windows、macOS、Linux）

### セットアップ

1. リポジトリをクローン
```bash
git clone https://github.com/sousakujikken/utavista.git
cd utavista
```

2. 依存関係をインストール
```bash
npm install
```

3. アプリケーションをビルド
```bash
npm run build
```

### FFmpeg について

動画書き出しには FFmpeg / FFprobe を使用します。別途インストールする必要はありません。

- 開発時（`npm run electron`）は devDependencies の `ffmpeg-static` / `ffprobe-static` を使用します。
- パッケージ時（`npm run package`）は `scripts/bundle-ffmpeg.cjs` が対象 OS・アーキテクチャ用のバイナリをアプリの `Resources/ffmpeg/` に同梱します。ビルド環境と異なる組み合わせの ffmpeg は初回のみダウンロードされます。
- 環境変数 `UTAVISTA_FFMPEG_PATH` / `UTAVISTA_FFPROBE_PATH` で任意の実行ファイルを指定できます。

## 起動方法

### 開発モードでの起動

開発時は以下の2つのコマンドを**それぞれ別のターミナル**で実行します：

1. **開発用ビルドプロセスの起動**
```bash
npm run dev
```
このコマンドでRenderer（UI）の開発サーバーとMain（Electron）プロセスのビルド（watch mode）が並行実行されます。

2. **Electronアプリケーションの起動**

別のターミナルで下記のコマンドを実行してElectronアプリケーションを起動します。
```bash
npm run electron
```

### アプリケーションのパッケージ化（未検証）

```bash
npm run package      # 現在のプラットフォーム用
npm run package:all  # 全プラットフォーム用（Windows、macOS、Linux）
```

## 使い方

### 基本的な操作手順

1. **アプリケーションの起動**
   - Electronアプリケーションを起動すると、メインウィンドウが表示されます

2. **音声ファイルの読み込み**
   - 「音楽」タブから音声ファイル（MP3、WAVなど）をドラッグ&ドロップまたは選択
   - 波形が表示され、再生コントロールが利用可能になります

3. **歌詞の入力と編集**
   - 別途作成した歌詞ファイルを「歌詞」タブからJSONファイル読み込みボタンで読み込み
   - 「歌詞を編集」ボタンから歌詞エディタを開き、歌詞データを直接編集可能
   - 歌詞エディタでは以下の操作が可能：
     - フレーズテキストの編集（クリックで編集モード）
     - 開始・終了時刻の調整（ミリ秒単位）
     - フレーズの削除
     - 変更内容のリアルタイム反映とプロジェクト保存

### 歌詞データについて

歌詞データの詳細な仕様については、[docs/lyricsdata_format.md](./docs/lyricsdata_format.md) を参照してください。

#### 歌詞データの作成方法

正確なタイミング情報を含む歌詞データを作成するには、以下の方法を推奨します：

1. **音声ファイルの準備**
   - 対象楽曲のボーカルトラックをSTEM分離ツールで抽出
   - ボーカルのみの音声ファイルを準備

2. **LLMを使用した歌詞データ生成**
   - Gemini 2.5 proなどのマルチモーダル対応LLMを使用
   - 以下のデータをLLMに提供：
     - ボーカルトラックの音声ファイル
     - 歌詞のテキストデータ
     - `src/renderer/data/testLyrics.json` をサンプルとして提示
   - LLMに対してUTAVISTA形式の歌詞データ生成を依頼

この手法により、フレーズ・単語・文字レベルでの精密なタイミング情報を含む歌詞データを効率的に作成できます。

4. **タイミングの設定**
   - タイムライン上でフレーズマーカーをドラッグして開始/終了時間を調整
   - 階層構造（フレーズ→単語→文字）でより細かいタイミング制御が可能
   - Ctrl/Cmd+ホイール（トラックパッドのピンチ）でタイムラインを拡大縮小（マウス位置を基準、2秒〜曲全体）

5. **シーン設定**
   - 「シーン」タブの「シーン設定プリセット」から内蔵プリセット（01A〜14B）またはユーザープリセットを選んで「適用」
   - 「基本シーン設定」でフォント、色、モーション、タイポグラフィエフェクトを調整（全オブジェクトに継承）
   - 出現・消失・継続・画面全体で選んだモーションの固有項目（例：bounce の落下の高さ）と、ONにしたエフェクトの詳細項目だけが表示されます
   - 同じ画面の「共通Post FX」で、画面全体に掛かるシェイク・グリッチ・色調などを設定
   - リアルタイムプレビューで即座に結果を確認

6. **単語・フレーズごとの個別設定**
   - タイムライン上でフレーズまたは単語マーカーを選択し、「シーン」タブを「選択オブジェクト」モードに切り替え
   - ここで変更した値はその単語・フレーズの個別設定になり、「単語 → フレーズ → 基本シーン設定」の順に優先されます
   - 文字を選んだ場合は、その文字を含む単語へ設定します
   - 「個別設定を解除して親設定を継承」で、親（フレーズまたは基本シーン設定）の値に戻せます
   - 活用例：サビだけ文字サイズを大きくする、特定の単語だけ色や出現モーションを変える

7. **動画のエクスポート**
   - 「プロジェクト」タブの「動画出力」で長辺解像度、動画品質（CRF）、フレームレートを設定（アスペクト比はコンテンツタブで設定）
   - **出力範囲の選択**：
     - 「カスタム時間範囲を使用」チェックボックスで全区間 or 指定範囲を選択
     - チェック時は開始時間・終了時間を「MM:SS.mmm」形式で指定可能
     - 部分的なプレビューや特定シーンの抽出に便利
   - 「動画を出力」で保存先を選ぶと書き出しを開始。書き出し中に他のタブへ移動しても進行状況は保持されます
   - H.264はハードウェアエンコードを優先し、対応しない解像度・フレームレートではソフトウェアエンコードに切り替えます（その場合は書き出しに時間がかかります）
   - 音声はYouTubeのアップロード推奨に合わせ、AAC-LC・48kHz・ステレオ（384kbps指定）で出力します
   - 背景タイプが「透過」のときは、ボタンが「透過動画を出力（ProRes 4444）」に変わり、アルファチャンネル付きの .mov で出力します（音声は非圧縮PCM、動画品質の設定は使いません）

8. **字幕・静止画の書き出し**
   - 「字幕（SRT）出力」：歌詞のフレーズ開始・終了時刻を使い、SubRip字幕ファイルとして書き出し
   - 「静止画（PNG）出力」：タイムラインの現在位置を、背景・文字・共通Post FXを合成した1枚のPNGとして書き出し

### キネティック・シーンのモーションとプリセット

`KineticSceneTemplate` では、単語ごとに次の部品を選んで場面を組み立てます。「シーン」タブの「シーン設定プリセット」から内蔵プリセット（01A〜14B）を適用し、調整した設定をユーザープリセットとして保存できます。

- **出現／消失**（共通）: `slam` `slide` `scale` `collapse` `fall` `shatter` `noise` `instant` `soft` `anticipate` `spring` `bounce` `turnstile` `mask` `genie`
- **継続**: `still` `shake` `pulse` `breathe` `glitch` `compress`
- **画面全体**: `none` `cameraShake` `zoom` `rgbDrift` `afterimage` `whipPan` `zoomDive`
- **タイポグラフィエフェクト**（個別にON/OFF・同時合成可）: 文字シャッフル、反復複製、有機ディストーション、弾性破壊、文字オブジェクト放出、文字曲面、可変ウェイトパルス、キネティックカーニング、ベースラインウェーブ、カラオケ塗り、二重輪郭インパクト

各モーションの詳細は `/docs/motion-composition.md`、参考にした公開事例は `/docs/motion-reference-implementations.md` を参照してください。

### プロジェクトファイルの管理

- **保存**: 「プロジェクト」タブの「保存」またはCtrl/Cmd + S でプロジェクトを保存（.uta形式）。どの編集欄にフォーカスがあっても保存できます
- **別名で保存**: 「別名で保存」またはCtrl/Cmd + Shift + S
- **開く**: 「読み込み」またはCtrl/Cmd + O。`.uta` ファイルのダブルクリックや「プログラムから開く」でも読み込めます
- **自動保存**: 作業中の変更は自動的に保存され、次回起動時に復元できます
- **終了時の確認**: 保存していない変更があるときは、閉じる前に「保存して終了／保存せずに終了／キャンセル」を確認します（保存せずに終了しても自動保存には残ります）。未保存の変更があるとプロジェクトタブに「● 未保存の変更があります」と表示されます
- **元に戻す／やり直し**: Ctrl/Cmd + Z で元に戻す、Ctrl/Cmd + Shift + Z または Ctrl + Y でやり直し
- **再生・一時停止**: Space キー（入力欄の操作中を除く）


# サイドパネルのUIルール

サイドパネル（シーン／コンテンツ／プロジェクト／書き出し／設定）は、近接・整列・反復・コントラストの原則に沿って、次のルールで組み立てます。色・余白・角丸は `src/renderer/styles/components.css` の CSS 変数を使い、色コードを直接書かないでください。

## 余白と配置（整列）

- 各タブの最上位要素には `.panel-content` を付けます。内側の余白は `--space-md`（16px）で、全タブのカードの左端がそろいます。
- タブの中にさらに `.panel-content` を入れた場合（ビート検出パネルなど）、内側の余白とスクロールは外側のものを使います。
- タブ名が見出しの役割を持つため、タブの先頭に大見出し（`h2`）は置きません。

## カードと見出し（近接・反復）

- 関係する項目は `Section` コンポーネント（`.common-section`）のカード1枚にまとめます。カード同士の間隔は `--space-md` です。
- カードの間に区切り線（`<hr>`）は入れません。カードの枠と区切りが二重になるためです。
- カード内で操作の流れが変わる場合（例: プリセットを「選んで使う」と「保存する」）は、グループを分けて細い区切り線を入れます。ボタンは、それが働く入力欄のすぐ下に置きます。
- カードの見出しは `.common-section-title`（`--text-subtitle`・太さ600・`--text-primary`）だけを使います。
- 説明文は `--text-small`・`--text-muted` にします。
- 入力欄のラベルは入力欄の上に置き、末尾にコロン（`:`）は付けません。

## ボタンの色（コントラスト）

| 種類 | 用途 |
| --- | --- |
| `primary`（ピンク） | カード内の主操作。原則としてカードに1つまで（例: 保存、適用、動画を出力） |
| `secondary`（灰色） | 補助的な操作（例: 別名で保存、読み込み、新規保存、元に戻す） |
| `danger-outline`（赤枠） | 削除など取り消せない操作 |
| `danger`（赤） | 実行中の処理の中止など、すぐ目に留まる必要がある操作（例: 書き出しのキャンセル） |

- 成功・警告・情報の色（緑・橙・青）は、状態を伝えるメッセージにだけ使い、ボタンには使いません。
- 選択中の状態（タブ、モード切替）とフォーカスの表示には、アクセントカラー（ピンク）を使います。

## 表示専用の情報

- 操作できない値を、無効化した入力欄で見せることはしません（押せそうに見えて押せないため）。
- 表示専用の値は、入力欄より一段暗い背景の情報欄に表示し、どこで変更できるかを添えます（例: 書き出しタブの出力サイズ）。

# シーン設定アーキテクチャ

## 基本方針

描画エンジンは `KineticSceneTemplate`（キネティック・シーン・コンポーザー）に固定する。ユーザーは完成形のテンプレートを切り替えるのではなく、モーション、タイポグラフィ効果、レイアウトをまとめた「シーン設定プリセット」を、基本設定または選択オブジェクトへ適用する。

設定の解決順序は次の通り。

1. 選択単語の個別設定
2. 親フレーズの個別設定
3. 基本シーン設定

文字を選択した場合は、その文字を含む単語を編集対象に正規化する。これにより歌詞の一文字ずつへタイミングと設定を割り当てる作業を避けつつ、単語単位の演出を作れる。

旧プロジェクトに別のテンプレートIDが保存されていても、読み込み時に `kineticscenetemplate` へ正規化する。既存のテンプレート関連フィールドはファイル互換のため当面残すが、UIからテンプレート階層や切り替えは公開しない。

## 全シーン共通 Post FX

Post FXは背景、文字、装飾をステージへ合成した後に、一つのPixiJSフィルターとして適用する。

- カメラシェイク
- ズーム
- 傾き
- グリッチ
- 色相回転
- 色収差（RGB分離）
- ビネット
- フィルムグレイン
- 走査線
- 彩度・コントラスト

ノイズとグリッチは再生時刻から計算するため、同じ設定と時刻には同じ結果を返す。設定はアプリ共通のローカルストレージへ保存され、すべてのシーンに一度だけ作用する。

## 参照実装について

[kemushiboy/pv-tool](https://github.com/kemushiboy/pv-tool) の全体合成後にPost FXを適用する設計と、効果の分類を参考にした。ただし同リポジトリのライセンスは非商用条件を含むため、ソースコードやシェーダーは移植せず、UTAVISTA側で独立して実装している。
